# SentinelGrid Frontend Dashboard

Next.js Mission Control Command Center for the Gujarat CCTV Surveillance & Analytics Platform.

## Features
- **Real-Time Alert Feed**: Instant notifications with vehicle license plate, severity level, location, and snapshot.
- **GIS Map Tracking**: Leaflet & OpenStreetMap visualization of live cameras and cross-camera vehicle routes.
- **Multi-Camera Grid**: Live stream surveillance monitoring.
- **Watchlist Management**: Add, update, and search suspect/stolen license plates.
- **Searchable Audit Logs**: Historical detection query interface.
